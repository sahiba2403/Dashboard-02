# Customer Churn Analysis Dashboard

## 📊 Project Overview
This project analyzes customer churn data to understand why customers leave and identify key factors affecting retention.

## 🛠 Tools Used
- Power BI
- Data Cleaning
- Data Visualization

## 📈 Key Insights
- Month-to-month customers have the highest churn
- Long-term contracts reduce churn
- Female customers show slightly higher churn (minimal difference)
- Contract type impacts churn more than gender

## 📁 Files
- Power BI Dashboard (.pbix)
- Dataset
- Screenshot

## 🎯 Outcome
Built an interactive dashboard to analyze customer behavior and improve retention strategies.
